12C – Regra dos 90 dias (só com o campo “over rolling” marcado)

Onde: depois do bloco da ZPPT_OEST (bloco 10A).
Buscar: "Regra para ESTOQUE ACABADOU OU SEMI-ACABADO:

  "Regra para ESTOQUE ACABADOU OU SEMI-ACABADO:
  "considerar somente lotes estocados a mais de 90 dias.
* RDM 334163 - Regra corrigida: a data não era lida e o filtro de faixas (com "E")
*              não separava nenhum material. Decisão funcional: vale para todas as
*              faixas e somente para aproveitamento de over rolling (campo P_OVER).
*  lit_mchbcar[] = it_mchbcar[].
*  DELETE lit_mchbcar WHERE matnr BETWEEN '12000000' AND '12999999' AND
*                           matnr BETWEEN '10000000' AND '11999999' AND "RDM 271193
*                           matnr BETWEEN '71000000' AND '71999999'. "RDM 271193
*
*  IF lit_mchbcar[] IS NOT INITIAL.
*    lv_data_estoque = sy-datum - 90.
*    LOOP AT lit_mchbcar ASSIGNING <fs_mchbcar>.
*      IF <fs_mchbcar>-ersda > lv_data_estoque.
*        DELETE it_mchbcar WHERE matnr EQ <fs_mchbcar>-matnr AND
*                                charg EQ <fs_mchbcar>-charg.
*      ENDIF.
*    ENDLOOP.
*  ENDIF.

  TYPES: BEGIN OF ty_lote_novo,
           matnr TYPE zrnsdt_mchbcar-matnr,
           charg TYPE zrnsdt_mchbcar-charg,
         END OF ty_lote_novo.
  DATA lt_lote_novo TYPE HASHED TABLE OF ty_lote_novo WITH UNIQUE KEY matnr charg.

  IF gv_over = abap_true.

    lv_data_estoque = sy-datum - 90.

    "Lotes com algum estoque mais novo que 90 dias (mesmo critério do original)
    LOOP AT it_mchbcar ASSIGNING <fs_mchbcar> WHERE ersda > lv_data_estoque.
      INSERT VALUE #( matnr = <fs_mchbcar>-matnr
                      charg = <fs_mchbcar>-charg ) INTO TABLE lt_lote_novo.
    ENDLOOP.

    "Remove esses lotes do estoque em uma única passada
    IF lt_lote_novo IS NOT INITIAL.
      LOOP AT it_mchbcar ASSIGNING <fs_mchbcar>.
        IF line_exists( lt_lote_novo[ matnr = <fs_mchbcar>-matnr
                                      charg = <fs_mchbcar>-charg ] ).
          DELETE it_mchbcar.
        ENDIF.
      ENDLOOP.
    ENDIF.
    FREE lt_lote_novo.

  ENDIF.
